# 景区与餐饮游玩发现功能验收

日期：2026-11-13（北京时间）。

## 已实现

- 旅行智能体的行程地图下新增“景区清单与吃喝游玩推荐”，原动态路书推荐面板复用同一功能。
- 高德搜索限制城市/区县，或以指定位置周边5公里查询；对返回的行政区信息再次过滤，避免无效城市参数造成全国结果。餐饮与游玩按类别筛选，支持加载后续页、去重、最多8页，并提示200条上限和搜索并非全量。
- 新增 POST /api/discovery/，支持 search、catalog、audit。search 优先使用 AMAP_WEB_SERVICE_KEY；未配置时浏览器使用现有 JS SDK Key。不会把 JS Key 当 Web 服务 Key。
- 查询结果显示高德来源、查询时间、评分、人均、营业时间；缺失保持未知，不编造营业状态、交通时间和游玩时长。地图查看使用 GCJ-02 坐标。
- 景区名录本地保存373条第三方5A候选，保留原始数据、来源与 CC BY-SA 4.0 说明；与两份已整理官方景区资料分层展示。三峡之巅归属奉节，恩施大峡谷含官方双片区参考顺序；历史资料明确要求核实当前运营。
- 行程检查会提示已整理景区的城市冲突与预约、末班、步道等核实项；不将未匹配误报成“没有景区”或“全部查全”。
- 候选按日期在浏览器保存，支持移除；动态路书可将真实坐标候选加入当天路线。兼容读取原面板已保存候选；新保存使用独立版本键，原数据不删除。
- 修改关键词/城市、切换日期或停止查询会取消旧查询，并阻止迟到响应覆盖当前结果；供应商失败不会清除已保留候选。

最终常驻版本：`http://localhost:3010/agent/`。正式构建部署后，`node scripts/discovery.browser.mjs http://localhost:3010` 和 `node scripts/discovery-roadbook.smoke.mjs http://localhost:3010` 均通过；service:status 返回 running=true、health.status=ready。此次验证没有调用真实下单或付款。

## 明确限制

这不是全国景区全覆盖验收。373条是第三方5A候选版本，4A/3A及非A级景点主要依赖按地区高德检索；尚无完整、已核对的全国基准清单。详细官方内部资料目前仅整理两处，其他景区明确显示资料缺口。搜索到 POI 不代表已验证完整内部路线。

当前没有服务端 Web 服务 Key 的真实联调证据：服务端搜索的参数、错误和分页用注入响应测试，浏览器 JS SDK 路径则做了真实调用。没有实时排队、到达时营业、预约库存或实际绕路时间能力。

没有将来源混杂的15.8万条开放地点库直接导入，也没有复制未明确许可的第三方项目代码。全国覆盖需要继续逐省核实名录并对账；数据来源和许可边界记录在前两份调研文档。
