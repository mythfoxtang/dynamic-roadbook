# 国内机票与住宿：实测结论及验收

验证日期：2026-11-09，北京时间。主体为个人开发；住宿面向经济型连锁、民宿、客栈及未标星住宿，默认最高参考价 300 元。正式入口 `/travel/`，生产服务 `http://127.0.0.1:3010/travel/`；隔离的开发服务保留在 3012 端口。

## 可用范围与最终选型

当前选用途牛官方 MCP 作为真实国内查价来源，已配置用户提供的服务端凭据，并用正式 endpoint 实测酒店和机票。前端不需要再填 Key。凭据在 Git 忽略的 `.env.local`，没有写进本文件、浏览器代码或测试截图；部署到其他机器需要单独配置服务器环境。

查价链路已取得真实证据；创单链路完成了协议适配及模拟测试，**没有用真实旅客资料执行订单测试，也没有真实付款、出票或酒店确认记录**。这份交付不通过“全程不跳转、正式付款和履约全部验证”的验收。继续研究可以确定其他接入路线，但不能用当前 Key 获得不存在于工具列表中的支付和查单权限。

## 酒店结论

已实测中文城市、人民币预算、分页、酒店和房型详情。网页有城市/县、日期、人数、儿童年龄、房间数、关键词及 POI 查询；结果有预算、品牌、档次、评分、早餐、窗户、停车和可取消条件，默认保留未标星。房型可以再按床型、报价、可住人数、早餐和取消条件筛选。未知条件不会算作符合；最低参考价并不等于所选房型或整单金额。

| 真实查询 | 使用日期 | 返回与详情 | 判断 |
|---|---|---|---|
| 成都 | 11-16 至 11-17 | 读取两页，共 10 家；两轮详情分别返回 27、28 个房型报价 | 市区预算查价可用；实时结果会变化 |
| 丽江 | 11-23 至 11-25 | 首页 8 家，声明共两页；首家 16 个房型报价 | 已验证两晚查询；未把首页声称为全部库存 |
| 香格里拉 | 11-16 至 11-17 | 网页实测首页 8 家 | `cityInfo` 正确解析香格里拉市，酒店行使用上级“迪庆”，已兼容 |
| 芒康 | 11-16 至 11-17 | 实际回退到上海酒店 | 拒绝展示异地报价，返回 `CITY_MISMATCH`；当前来源未通过此县的覆盖验证 |

首轮成都请求预算 200–300，仍返回过 316 元的酒店。已增加前端预算过滤，不把供应商过滤视为严格保证；所有未加载页面、未知价格和预算内候选数量分别呈现。正式网页测试确认筛选只保留当前预算内数值报价。

多晚、多房的人民币字段没有足够明确的统一计价口径，代码保留原始详情报价，不把单价随意乘晚数或人数。详情、最终验价与官方支付页需核对一致。独卫、供暖、晚到接待等在列表没有稳定字段，不能因为酒店名称而声称已满足。

酒店文档与权限依据：[官方酒店接口](https://open.tuniu.com/mcp/docs/apidoc/mcp/hotelMCP.html)。迪庆行政层级核对：[迪庆州政府行政区划](https://diqing.gov.cn/xzqh.html)。当前城市校验仅针对有依据的上下级关系做兼容，不能将任意不同城市当作别名。

**酒店判断：适合作为个人项目的国内市区查价原型；不能凭这几组结果承诺长线所有县城覆盖、全平台最低价或完全站内支付。**

## 机票结论

真实发现了查询、舱位、预订须知、创单、取消五项工具。页面支持低价、起降时间、票面价格区间、周边出发、周边到达、中转六种查询模式，支持按供应商声明分页继续读取。已加载结果支持含税参考价、航司、机场、直飞、出发时间和明确余票筛选、排序及最多三个候选比较；具体舱位支持舱等、报价、明确免费重量行李及可退条件。

| 真实查询 | 出发日与条件 | 返回候选 | 当次每成人含税参考区间 |
|---|---|---:|---:|
| 上海 → 成都 | 11-16，默认低价 | 10 | 690–760 元 |
| 北京 → 上海 | 11-23，06:00–12:00，1 成人 1 儿童 | 10 | 600–834 元 |
| 成都 → 拉萨 | 11-23，票面区间 200–1000 | 10 | 490–640 元 |

这是查询时快照，不能当作当前可售保证。上海→成都另有真实 9 个舱位详情及官方预订须知；网页实测直飞筛选和详情读取。实际返回有 `{result: "JSON字符串"}` 包装，已适配，并加回归测试。

只在票面和税费都为有效数值时相加。缺税费不按零税费计算；儿童参考查询不代表拿到了儿童结算价，也不将成人价乘总人数作为整单价。婴儿票、往返联程统一交易和支付后退改未接入。身份证校验、其他证件生日/有效期、成人儿童年龄、人数和明确余票不足有提交前检查。正式创建订单仍需真实旅客资料、用户确认和供应商验价。

文档依据：[官方国内机票接口](https://open.tuniu.com/mcp/docs/apidoc/mcp/flightMCP.html)。实测只有供应商返回的候选集合，不能把 10 个返回航班声称为该航线当天所有可售航班。

**机票判断：国内查价与舱位规则查询可用；当前个人 Key 不能据此承诺独立收款、出票回调、完整查单及支付后售后闭环。**

## 不跳转付款的完整研究结论

| 路线 | 能证实的能力 | 当前项目的结论 |
|---|---|---|
| 途牛个人 MCP | 国内机票/酒店查价、详情及创单工具；付款返回官方 URL | 已实际接通查价；不满足原定本站独立支付目标 |
| 同程/艺龙酒店开放平台 | 酒店创单，现付/预付；合作指南讨论闭环和订单中心位置 | 酒店闭环重点候选；尚无本账号合作授权。非担保到店付可避开本站在线收款，但必须有可售产品及确认状态 |
| 美团酒店分销 | 官方介绍各价格带国内库存、API 模式及商务开发流程 | 经济住宿扩大覆盖的候选，未取得账号权限，不能冒充已接入 |
| 去哪儿商旅开放平台 | 官方说明国内机票搜索、预订、支付、查单、退改接口 | 机票完整交易的候选，需要申请及联调；公开介绍不证明个人立即可获生产权限 |
| 携程商旅、飞猪/阿里商旅 | 官方存在业务 API 和企业集成入口 | 不能把订单数据查询、供应商上传运价接口等混作个人消费查价/支付权限 |
| LiteAPI / Duffel 原有实验 | 海外或测试环境的技术验证 | 不计入国内经济住宿与正式支付验收 |

依据：[艺龙合作流程](https://open.elong.com/doc/info/plat-guide-cooperation_branch)、[艺龙创单及支付类型](https://open.elong.com/doc/info/cn-api-meta-hotel_order_create)、[美团酒店分销](https://developer-distribution.meituan.com/)、[美团分销条款](https://mf.meituan.com/domestic-contract.html)、[去哪儿开放平台](https://open.qunar.com/detail/open)、[携程商旅开发者平台](https://openapi.ctripbiz.com/)、[阿里商旅 API 目录](https://open.alitrip.com/docs/api_list.htm?scopeId=12500)。艺龙合作流程页更新时间较旧；去哪儿详情页本次直接打开超时，相关接口范围取得自其官方搜索索引，尚未以合作账号验证。

本站独立付款上线仍需：供应商授予的支付/结算权限、验价与库存确认、支付签名及通知核验、订单查询和履约状态同步、重复通知幂等、退款/退改、失败对账。当前没有对应正式凭据和接口契约，未伪造支付按钮或擅自嵌入官方支付页。

## 测试证据与复现

最终验证：Node 全套 63/63 通过；开发服务与 3010 生产服务上的 fixture 浏览器测试均通过；真实只读网页测试通过；`npm.cmd run build` 退出码 0。生产 `/travel/` 和账号状态接口均返回 200、服务端环境 Key 已连接；检查 40 个前端构建文件与公开状态响应，未发现供应商密钥。

- `lib/travel.test.mjs`：查询校验、未知数据、真实结构兼容、分页去重、预算/设施/房型/舱位筛选、账号隔离、报价过期、确认及重复创单、结果未知不重试、订单取消、PKCE 和限流；使用明确 fixture，不证明真实出票。
- `lib/travel-vault.test.mjs`：在独立临时目录和子进程验证加密保存、服务重启恢复及删除，不改用户凭据。
- `scripts/travel-ui.smoke.mjs`：浏览器拦截 fixture，验证 60 家候选、筛选、比较、修改条件后禁止沿用旧报价、确认创单、护照字段、手机宽度及浏览器错误。
- `scripts/travel-live-readonly.mjs`：真实多城市、多航线只读接口验证。私有结果在 `.automation/travel-live-report.json`；保留修复前失败记录。
- `scripts/travel-ui.live-readonly.mjs`：正式本地网页连接真实途牛接口，验证成都翻页/预算/房型、上海→成都筛选/舱位/须知、香格里拉行政区域兼容、芒康异地结果拦截；代码禁止 book/cancel。

命令：`npm.cmd run test:travel`、`npm.cmd run test:travel:ui`、`npm.cmd run build`。真实只读脚本会消耗实际供应商额度，不包含在常规单元测试中；不要反复全量运行。官方限额为全账号所有 Key 共用每分钟 5 次、每日 50 次，本站显示的额度仅为进程内估算，不能当作官方剩余额度。[官方限额](https://open.tuniu.com/mcp/docs/guide/ratelimit.html)

查询缓存 2 分钟、详情缓存 1 分钟、提交用详情保留 5 分钟。未支付创单前写入加密本地意图记录，网络不确定时禁止自动重试。订单记录只表示本站已知状态，不假设已经支付、出票或入住确认；支付后未实现官方自动同步。
