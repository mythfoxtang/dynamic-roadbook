## 当前研究证据

- 途牛酒店接口有中文城市、`prices` 人民币区间、人数、POI、翻页、房型详情与自动验价创单。
- 途牛国内机票接口有六种搜索模式、翻页、含税字段、舱位、行李与退改、预订信息要求、创单及未支付订单取消。
- 公开酒店和国内机票文档都返回外部支付链接；不能据此声称全站内付款。
- 用户随后提供了供应商 Key，已配置在本机 Git 忽略的 .env.local。获得真实国内酒店、房型、航班及舱位证据；无真实下单和付款。
